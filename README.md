# Openclaw Docs Final

พร้อมสำหรับ GitHub Pages แล้ว

## ไฟล์สำคัญ
- `index.html` — หน้าเว็บหลัก

## วิธีอัปขึ้น GitHub Pages แบบเร็ว
1. สร้าง GitHub repository ใหม่
2. Upload ไฟล์ในโฟลเดอร์นี้ขึ้น repo
3. ไปที่ **Settings > Pages**
4. ใน **Build and deployment** เลือก:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/root`
5. กด Save
6. รอ 1-3 นาที
7. จะได้ลิงก์ประมาณ:
   - `https://YOUR_USERNAME.github.io/REPO_NAME/`

## หมายเหตุ
- ถ้าต้องการแก้ไขหน้าเว็บ ให้แก้ที่ `index.html`
- ถ้าอัปไฟล์ใหม่ทับของเดิม GitHub Pages จะอัปเดตให้เอง
